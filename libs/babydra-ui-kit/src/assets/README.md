# Tabler Icons

The SVGs in `light/` and `dark/` are adapted from [Tabler Icons](https://github.com/tabler/tabler-icons). They use the filled set where it has a matching symbol. Exact Wi-Fi, audio, and screenshot drawing symbols use Tabler's outline files because those names have no filled variant. Each SVG includes a comment naming its source icon. Colors are set for BabyDra's light and dark themes so the assets keep working with the existing embedded icon loader.
